Sambungkan HP kasir

HP/perangkat harus tersambung ke WiFi yang sama dengan komputer ini.

  1. Buka aplikasi Savve di HP Android.
  2. Tekan Cari Otomatis, atau ketik alamat di bawah ini.
  3. Login dengan akun kasir.

Perangkat tanpa aplikasi (laptop/tablet) bisa membuka alamat ini di Chrome. Jika muncul peringatan keamanan, pilih Lanjutan → Lanjutkan. Ini normal untuk server lokal.
